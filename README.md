# Prof. Garg's AI and Analytics (GAIAR) Lab

Personal site and project timeline, built with Jekyll.

## Local development
1. Install Ruby + Bundler, then `bundle install` (or use the included `.devcontainer` for a containerized setup)
2. `jekyll serve`
3. Open [http://localhost:4000/](http://localhost:4000/)

## Editing content
* Site title, bio, and social links: [`_config.yml`](_config.yml)
* Project timeline entries: [`_data/projects.yml`](_data/projects.yml)
* Header/bio markup: [`_includes/header.html`](_includes/header.html)
